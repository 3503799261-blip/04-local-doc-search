# 校园网络操作手册（虚构教学资料）

本文仅作信息检索演示，服务名称与规则均为虚构。

## 无线网络连接

在教学楼选择 Campus-Demo 无线网络，打开浏览器进入认证页，使用校园账号和密码登录。首次连接需要阅读网络使用说明。请避免连接名称相近的陌生热点，也不要向其他人透露账号密码。

## 密码重置

忘记网络登录密码时，进入校园服务台的账号管理页，通过绑定邮箱接收验证码，验证成功后设置新密码。若邮箱无法接收邮件，请携带校园卡到信息中心核验身份。修改密码后，手机和电脑保存的旧密码也需要一起更新。

## 常见断网排查

网络经常断开时，先关闭无线网卡后重新连接，再检查是否开启了代理。浏览器显示认证过期时需要重新登录。若多台设备同时无法联网，请在故障工单中填写楼栋、楼层、发生时间和错误提示，信息中心据此排查覆盖与设备问题。
